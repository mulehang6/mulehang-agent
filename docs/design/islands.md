# Islands 设计规范

## 目的

工具调用和已提交问答的详情采用同一套 Islands（岛屿）层级：触发器保持紧凑、详情作为独立整体出现，内部内容块清晰分组但不堆叠为厚重的嵌套卡片。

## 层级与布局

1. 工具行或 Answers 标题是独立触发器，不能被详情卡片包裹。
2. 展开后在触发器下方放置一个外层岛屿：`DetailIslandsOuterBackground`、`12.dp` 圆角、`AppLine` 的低对比度细边线，内边距 `16.dp`。该表面必须与内层岛屿不同。
3. 外层岛屿内的输入、输出，或问题、回答分别是相邻的内层岛屿：统一使用 `DetailIslandBackground`、`8.dp` 圆角和低对比度细边线，块间距 `12.dp`。
4. 普通内层岛屿彼此使用相同背景色；外层与内层不可同色。依靠顺序、留白和文字层级区分内容，不为各个内层岛屿分别着色。错误内容例外，使用克制的危险色表面及 `AppDanger` 前景，但仍是同一外层岛屿的一部分。
5. 详情卡片左边界与相应标题文字对齐。工具详情不显示“输入”“输出”标签；问答按“问题在前、回答在后”呈现。

## 交互

- Hover 仅提高触发标题文字的颜色，不添加背景、描边、水波纹或布局变化。
- 交互命中区应限于实际标题文字；左侧图标、展开后的详情内容和空白区域不应触发展开或标题高亮。
- 展开箭头保留固定布局占位，仅在标题 hover 时显示，并通过旋转表示展开状态。
