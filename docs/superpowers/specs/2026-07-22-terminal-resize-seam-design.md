# 终端拖动缝隙修复设计

## 目标

修复桌面端嵌入式终端左侧亮色边缘，以及上下拖动终端高度时顶部边界出现的白色或黑色横向块。

## 根因

- `EmbeddedTerminalPanel` 在深色终端外层绘制了 `1.dp` 的完整 Compose 边框，因此左侧会持续出现亮线。
- 截图中拖动时变色的顶部横线是同一完整边框的上边；它随终端容器移动并与 Swing 合成层交界，因此重绘期间会呈现白色或黑色块。

## 方案

移除终端外层完整边框，保留圆角裁剪和现有深色背景。这样同时去掉左侧亮线与拖动时发生变色的顶部横线。

不修改 JediTerm、PTY、滚动条或拖动范围，不引入动画和新依赖。

## 验证

- IDEA 检查受影响 Kotlin 文件。
- 运行 `:desktopApp:test` 与 `:desktopApp:compileKotlin`。
- 按仓库限制不自动启动桌面应用；视觉结果由用户下次运行时确认。
