# 内嵌终端一体式顶部栏设计

## 目标

让内嵌终端的标签页、操作入口和内容区形成一个完整终端容器，贴近 IDEA 终端的层级，而不是额外套一层独立标题栏。

## 视觉与布局

- 顶部标签栏与终端内容使用相同的深色终端背景；两者之间仅保留低对比的一像素分隔线。
- 活动标签显示低对比背景与细边界，标签标题右侧内置“×”关闭入口。
- “+”紧随标签列表，而不是固定在顶部栏最右侧。
- 删除现有顶部栏最右侧、与标签脱离的关闭按钮。
- 保留标签列表的水平滚动，以支持多个终端页。

## 交互

- 点击标签切换当前终端页，点击标签内“×”关闭该标签。
- 点击“+”创建并选中一个新终端页。
- 在标签上右键打开上下文菜单：新建终端、关闭当前终端、关闭其他终端。
- “关闭其他终端”保留被右击的标签与其终端进程，释放所有其他会话，并将其设为活动标签。

## 状态与测试

- `TerminalTabsState` 新增保留单页、关闭其他页的纯状态转换，确保活动标签和会话释放目标可预测。
- 会话库新增按标签页关闭以外的批量释放入口，避免关闭其他页时误释放保留页。
- 单元测试覆盖：关闭右击页之外的标签、活动标签收敛、保留会话不被关闭。

## 范围

只调整 `EmbeddedTerminalPanel` 的顶部栏、标签操作和相关状态/会话逻辑；不修改终端进程创建、分割布局或右侧终端图标的行为。
