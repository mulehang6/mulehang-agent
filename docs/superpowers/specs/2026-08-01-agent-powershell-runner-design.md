# Agent PowerShell 执行器设计

## 目标

让 Agent 的一次性 PowerShell 工具具备 Kilo 同等的基础运行边界：确定的工作目录、并发输出读取、超时与取消、输出上限、版本探测缓存和可测试的错误行为。

## 决策

保留“一次工具调用对应一个 `pwsh` 进程”的模型，不与 UI 内嵌 PTY 复用。默认超时为 120 秒，调用方可请求更短或更长时间，最大为 600 秒。工具始终在受控工作区目录运行。

新增 JVM 内部进程执行器，负责启动、并发读取 stdout/stderr、输出限额、超时及取消后的两阶段终止。`DesktopPowerShellTool` 仅处理 PowerShell 7 可用性和结果格式；`DesktopToolSet` 负责将工作区和取消状态传入。

## 错误与输出

运行器返回退出码、双流输出和每流截断状态。超时或取消会先正常终止，短暂等待后强制终止；返回文本应明确区分超时、取消、启动失败及输出截断。输出不写入磁盘。

## 测试

覆盖工作目录、stderr 大量输出不会阻塞、超时、取消、输出截断、版本探测缓存及工具注册层的工作区传递。测试使用可注入的进程边界，避免依赖本机已安装的 PowerShell。
