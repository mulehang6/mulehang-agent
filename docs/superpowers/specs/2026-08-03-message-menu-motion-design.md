# 消息发送与菜单动效设计

## 目标

修复用户消息没有飞到最终卡片位置的问题，并让下拉菜单与右键菜单从其触发点自然展开。动效应清晰、快速、可中断，不改变现有业务状态和布局结构。

## 发送消息

发送后，最新用户消息直接在时间线最终位置进入，不再创建跨区域飞行副本。消息从下方约 8dp 轻微上移，同时由透明变为不透明，并从 0.98 缩放到 1；动画控制在 180–220ms，采用强 ease-out。

只有本次刚发送的最后一条匹配用户消息参与动画。历史消息、会话首次加载和内容相同的更早消息均保持静止；动画结束后立即清除临时进入标识。

## 菜单

下拉菜单从触发器朝向菜单的一侧生长；右键菜单从指针点击位置生长。进入使用 0.96 到 1 的轻微缩放、少量位移和淡入，退出更快。只动画 `graphicsLayer` 中的变换和透明度，不动画宽高或边距。

下拉菜单和右键菜单共用一组动效参数，但保留不同的变换原点：下拉菜单使用触发器对应的顶部边缘，右键菜单使用点击点对应的左上角。

## 验证

- 单元测试覆盖：必须等待真实目标、路径固定、菜单展开/收起参数及不同菜单原点。
- 运行 `:desktopApp:test` 与 `:desktopApp:compileKotlin`。
- 使用 IDEA 问题检查确认改动文件无新增错误。
- 检查 diff，确保不覆盖工作区中已有的其他改动。
