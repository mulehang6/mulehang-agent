# 工具交互动效与终端收起设计

## 目标

改善 Desktop 工具调用的可感知反馈：非终端工具的图标动效至少可见两秒；连续调用以双层卡片队列呈现；审批和提问交互以一致的弹出动效出现；提问卡替换默认 Android 风格输入框。终端面板新增仅收起、不终止会话的关闭入口。

## 范围与约束

- 仅修改 `desktopApp` 的 Compose Desktop 展示与展示状态，不改变 `shared` 协议或工具实际执行语义。
- 非终端工具的结果展示延后到开始后至少两秒；工具本身仍立即执行。
- 终端工具不施加延迟，且收起终端不得关闭标签页或 PowerShell 进程。
- 连续工具调用最多展示当前卡与一张后置预览卡；不平铺更多卡片。
- 不新增全局浮层，卡片仍位于既有对话时间线和 composer 上方交互区域中。

## 交互设计

### 终端收起

在终端标签栏右上角增加关闭图标，语义为“收起终端”。点击后由父级将终端面板设为不可见；`TerminalSessionStore` 和标签状态保持不变。再次通过既有终端入口打开时恢复原会话。

### 工具最短展示时长

工具开始事件出现时记录其本地展示起点。对于非终端工具，若结果在两秒内到达，则延迟展示完成状态至两秒届满；若结果较晚到达则即时展示。终端工具直接展示实际状态，不参与延迟。

### 工具卡片队列

相邻工具调用使用队列渲染：当前项处在前景，下一项在后方以 8dp 左右偏移、较小比例和较低透明度露出。队列推进时，当前卡横向滑出；后置卡同步上移、放大并提高透明度成为当前卡。第三及后续项不渲染预览，待轮到下一位时再显示。

### 审批与提问

审批卡和提问卡进入时统一采用淡入、向上位移和轻微缩放；离场则短促淡出上移。提问卡采用桌面式分区：小型状态标签、问题正文、选项按钮和自由输入区。自由输入区改为深色、无外描边的多行表面，包含弱提示文本和独立的强调色提交按钮，避免 Material 默认 `OutlinedTextField` 外观。

## 验证

- 为最短展示时长、终端工具豁免及双层可见队列补充单元测试。
- 为终端收起行为补充状态测试，确认会话不被释放。
- 使用 IDEA 检查每个改动文件的问题，并编译 `:desktopApp:compileKotlin`；运行相关测试。
