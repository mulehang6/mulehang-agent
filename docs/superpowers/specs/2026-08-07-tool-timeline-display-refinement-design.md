# 工具时间线展示收敛设计

## 目标

让工具调用在收起状态下更易扫读，并统一 Markdown 行内代码的透明背景强调色样式。

## 展示规则

- 多工具组的默认摘要使用英文 `Executed tools · N`。
- 单个可分组工具不创建 `ToolGroup`，直接渲染为工具行。
- `glob`、`glob_files` 与其他文件匹配工具映射为 `SEARCH`，复用放大镜扫描文本的图标，而非通用圆环。
- 非终端工具的收起行只显示图标与工具名；其输入参数仅在展开内容中显示。
- 终端工具的收起行只显示命令，不显示实现名（例如 `run_powershell`）；其命令仍可展开查看完整输入和输出。
- Markdown 的反引号行内代码统一使用蓝色强调文字且保持透明背景，覆盖普通 Markdown、列表和包含扩展 Markdown 的正文路径。

## 边界

- 不变更 `shared` 中的事件模型、工具协议、会话持久化或 Markdown 解析语义。
- 工具输出、失败状态、现有展开状态和标题切换动画保持原有行为。
- 不调整围栏代码块的样式；本次只处理反引号行内代码与 `==高亮==`。

## 验收

1. 单工具时间线中不存在 `Executed tools` 标题。
2. 两个及以上连续工具显示 `Executed tools · N`，且 `glob_files` 显示搜索图标。
3. 非终端工具参数仅在展开后可见；终端行仅显示命令。
4. 行内反引号代码使用应用蓝色强调文字，不再使用默认浅灰背景包裹框。
5. 相关单测、Kotlin 编译和 IDEA 问题检查通过。
